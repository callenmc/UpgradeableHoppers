# UpgradeableHoppers (Paper 1.20 - 1.21+)

A high-performance, production-ready Minecraft plugin for Paper 1.20+ allowing players to upgrade authentic vanilla `minecraft:hopper` blocks with genuine transfer speed acceleration and Vault economy integration.

## Key Features
- **Vanilla Block Preservation**: Works directly on real `minecraft:hopper` block entities.
- **Genuine Speed Scaling**: Truly accelerates item transfer rates from baseline (2 items/s) to Tier 5 (32 items/s).
- **Interactive Upgrade GUI**: Clean, exploit-proof chest-like interface.
- **Vault Economy Integration**: Automatically hooks into any Vault-compatible economy plugin.
- **Anti-Exploit Protection**: Eliminates shift-click dupes, cursor swaps, and rapid-click race conditions.
- **Multi-Storage Architecture**: Native Paper PersistentDataContainer (PDC) and optional SQLite database.
